# Breach Busters: Cyber Quest

A quick, playful cybersecurity training game. Work through six incident response scenarios, choose what you would do, and get a short explanation after each choice.

## Play

Open [`index.html`](index.html) in any modern browser. No build, install, account, or backend is needed. The game runs locally in the browser and makes no network changes.

## What you practice

- Recognizing phishing and payment scams
- Protecting passwords and multi-factor authentication codes
- Handling unknown USB devices and suspicious Wi-Fi
- Reporting lost devices and accidental data sharing

Your score, streak, and badges last only for the current session. The scenarios are educational examples, not a substitute for your organization's security process.
